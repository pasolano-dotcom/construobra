# CONSTRUOBRA PLUS

Aplicación web académica para estudiantes de Ingeniería Civil.

## Funciones
- Cálculo de volumen de concreto con desperdicio.
- Estimación de cemento, arena y grava según dosificación.
- Cálculo de ladrillos con juntas, aberturas y desperdicio.
- Áreas de rectángulos, triángulos y círculos.
- Volúmenes de prismas rectangulares y cilindros.
- Presupuesto en COP con subtotal, imprevistos y total.
- Exportación del presupuesto a CSV e impresión/guardado en PDF.
- Historial local de cálculos y nombre del proyecto.
- Diseño adaptable a celulares y computadores.

## Cómo abrir
Abre `index.html` con Chrome, Edge, Firefox u otro navegador moderno. No requiere instalación ni conexión a internet.

## Publicar en GitHub Pages
1. Crea un repositorio público llamado `CONSTRUOBRA`.
2. Sube `index.html` y `README.md` a la raíz del repositorio.
3. Ve a Settings > Pages.
4. En Build and deployment selecciona Deploy from a branch.
5. Selecciona la rama `main` y la carpeta `/(root)`, luego Save.
6. Espera a que GitHub Pages publique el sitio.

## Alcance y limitaciones
CONSTRUOBRA PLUS es una herramienta de apoyo académico para estimaciones preliminares. No realiza diseños estructurales, certificaciones de seguridad, verificaciones normativas ni análisis de resistencia. Las cantidades reales deben validarse con especificaciones técnicas y asesoría profesional.
